How The Detection Pipeline Works

The project combines image preprocessing, supervised learning, and web deployment to provide practical citrus leaf health assessment.

01

Data Collection

Leaf images are collected by class and screened for label correctness and visual quality.

02

Preprocessing

Images are converted to a standard size and normalized to stabilize training behavior.

03

Feature Vector Creation

Resized images are flattened into numeric vectors for machine learning classification.

04

Label Encoding

Class names are encoded into model-friendly numeric labels and stored for inference reuse.

05

Random Forest Training

The classifier is trained on split data and evaluated on a held-out test set.

06

Evaluation And Tracking

Accuracy and run metadata are written to monitoring files for transparent performance tracking.

07

Model Serialization

Model and encoder artifacts are saved and loaded by Flask for repeatable predictions.

08

Web Inference

Users upload a leaf image in the interface and instantly receive classification output.
